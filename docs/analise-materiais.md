# Análise dos materiais anexados

## Entrega atual
A imagem Projeto Integrador pede quatro páginas em HTML puro, sem CSS, com semântica, hierarquia de headings, navegação interna funcional e checklist de acessibilidade aplicado. Pede link do GitHub na branch entrega-1. Os quatro diagramas ilustram possibilidades de organização semântica; não se tentou reproduzir colunas e cores sem CSS nem usou tabela para diagramação.

## PDFs considerados
- Interface-Web-com-HTML-e-CSS.pdf: fundamentos de cliente/servidor, URL e documento HTML. Aplicados doctype, idioma, metadados e separação estrutura/apresentação.
- Interface-Web-com-HTML-e-CSS_Slides_Aula01.pdf: introdução à web e estrutura básica, usada como referência conceitual.
- Interface-Web-com-HTML-e-CSS_Slides_Aula03.pdf: categorias e elementos semânticos, aplicados conforme função do conteúdo.
- Interface-Web-com-HTML-e-CSS_Slides_Aula05.pdf: acessibilidade e prioridade da semântica nativa; aplicado ARIA somente como complemento.
- Revisao_HTML.pdf: referência central para estrutura, section/article/aside, títulos, navegação, formulários, tabelas e acessibilidade.
- Trabalho01.pdf: exercício anterior Conecta Tecnologia, com index.html e estrutura.txt e prazo próprio. Não foi confundido com a entrega atual. Seus critérios úteis de estrutura, alt, títulos e documentação foram aproveitados. O documento proíbe IA naquele trabalho específico; esta solução é apoio para o Projeto Integrador e deve ser revista pelo aluno conforme regras atuais da disciplina.
- Atividades.pdf (Semana 2, 3 páginas, conforme anexo identificado): prática de estrutura a partir de layout; não é a exigência de quatro páginas do integrador.
- Atividades.pdf (Semana 6, 4 páginas, conforme anexo identificado): correção de acessibilidade do estúdio de tatuagem e teste com NVDA, utilizado como referência para labels, alt, links e títulos.
- Atividades.pdf (fechamento HTML, 8 páginas): apresenta SATEC 2026, tabela de programação, perfis em article, formulário e auditoria. É a referência temática do HTML fornecido. Proíbe IA em etapas específicas de exercício e permite uso em etapa posterior de comparação; não se inventaram auditorias ou autoria manual.
- Atividade.pdf: exercício Decifre a URL; utilizado para distinguir caminhos, parâmetros e fragmentos.
- Interface-Web-com-HTML-e-CSS_Slides_Aula13.pdf: introdução a CSS e separação entre significado e aparência. O CSS não foi incluído porque a entrega atual o proíbe.
- Interface-Web-com-HTML-e-CSS_Aula13.pdf: guia de CSS, consultado como contexto, sem aplicar estilos nesta etapa.

## Outros anexos
O index.html fornecido já apresenta SATEC 2026, mas referencia CSS, imagens e destinos ausentes. Foi reorganizado em quatro páginas e recebeu ilustrações locais. textos.txt apresenta Conecta Tecnologia, tema de outro exercício; não foi misturado ao evento SATEC.

## Limites
Não foi localizado nos textos anexados um enunciado que nomeie as quatro páginas do Projeto Integrador. A divisão adotada é uma proposta baseada no HTML enviado, não uma afirmação sobre exigência explícita do professor. Datas, nomes, vagas e certificados são do cenário fictício, não informações verificadas sobre um evento real.
A revisão do conteúdo textual dos PDFs e dos anexos não substitui conferência de eventuais orientações adicionais do professor.
