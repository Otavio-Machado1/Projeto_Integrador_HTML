Inscrição demonstrativa

Formulário demonstrativo

Use somente dados fictícios. Este formulário demonstra marcação e validação nativa do navegador. Não cadastra participantes, não envia e-mail e não armazena inscrições. Os campos não têm atributo name para não incluir os valores na URL.

Limites da demonstração

Ao acionar o botão com campos válidos, o navegador retorna a esta seção. Isso não confirma uma inscrição; nenhum cadastro é realizado.

Termos do exemplo acadêmico

Os dados devem ser fictícios. A participação, as vagas e os certificados descritos neste site fazem parte de um exercício, sem oferta real.

Perguntas frequentes

A inscrição é gratuita?

No cenário fictício, a inscrição seria gratuita e limitada a 300 vagas. Este site não oferece vagas reais.

Recebo certificado?

No cenário fictício, haveria certificado de 20 horas mediante frequência mínima. Este projeto não emite certificados.

Posso participar de mais de uma oficina?

No cenário fictício, seria possível escolher oficinas com horários diferentes.

Recursos de acessibilidade

As quatro páginas incluem link de salto, títulos hierárquicos, navegação consistente e identificação da página atual. O formulário tem rótulos e as tabelas possuem cabeçalhos.

Os testes de teclado, leitor de tela e ferramentas externas devem ser concluídos conforme o checklist do projeto.

Privacidade na demonstração

Não informe dados pessoais reais. Não existe servidor de cadastro neste projeto.
